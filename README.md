# Calculadora de Média em C

### Professora Karina Alves de Melo

## 📚 Sobre o Projeto

Este projeto foi desenvolvido em linguagem C para calcular a média de duas notas, permitindo ao usuário escolher entre média aritmética e média ponderada.

## 🎯 Objetivo

Praticar os conceitos básicos de programação em C, utilizando entrada de dados, variáveis, estruturas condicionais e operações matemáticas.

## ⚙️ Funcionalidades

* Solicitar o tipo de média desejada.
* Receber duas notas do usuário.
* Calcular a média aritmética.
* Calcular a média ponderada.
* Exibir o resultado na tela.
* Informar quando o tipo de média digitado for inválido.

## 🧮 Tipos de Média

### Média Aritmética (A)

Calcula a soma das duas notas dividida por 2.

`Média = (Nota 1 + Nota 2) / 2`

### Média Ponderada (P)

Calcula a média considerando os pesos 3 e 7 para a primeira e a segunda nota, respectivamente.

`Média = (Nota 1 × 3 + Nota 2 × 7) / 10`

## 💻 Tecnologias Utilizadas

* Linguagem C
* Biblioteca `stdio.h`

## 📌 Exemplo de Execução

```text
Digite o tipo de media (A - Aritmetica / P - Ponderada): a
Digite a primeira nota: 7
Digite a segunda nota: 4
Media: 5.5
```

## 🛠️ Conceitos Utilizados

* Variáveis
* Tipos de dados
* Entrada e saída de dados (`scanf` e `printf`)
* Estruturas condicionais (`if`, `else if` e `else`)
* Operadores aritméticos

## ✅ Conclusão

O projeto demonstra a aplicação de conceitos fundamentais da linguagem C para desenvolver um programa simples de cálculo de médias, com diferentes métodos de cálculo escolhidos pelo usuário.
